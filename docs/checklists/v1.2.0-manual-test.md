## 1. 本轮（2026-09-12）新增 / 修复

### 1.1 排版尺度（实测台 + 真机复测）

* [x] 全文行高统一（正文 / 列表项 / 引用块 / 表格单元格同源），相邻块只有一个间距 10.5px，标题与分隔线取 2× 档
* [x] 列表标记与同行文字基线对齐；项间距与段间距一致（20.8px → 10.5px）；每级嵌套缩进 55px → 27.3px
* [x] 引用块、表格单元格上下留白相等（原 12/22px、12.5/8.5px）
* [x] 源码软换行不再多出一行（两行文字就是两行）
* [x] 标题折叠按钮悬挑到正文列外：H 标题与正文左缘对齐（均为 318px），按钮与文字留 8px

### 1.2 列表项行首 Backspace（本轮修，语义为「断开列表」）

* [ ] 无序列表：行首退格 → 该项变成普通行（列表就此断开），**上下方向键可正常移动**
* [ ] 有序列表：行首退格 → 该项变成普通行，**后半段延续编号**（不是从 1 重来）
* [ ] 空项行首退格 → 变成普通空行（不留多余空段落、标记不漏进正文）
* [ ] 列表第一项行首退格 → 变成普通行，列表整体下移
* [ ] 嵌套项行首退格 → 上升一级（回到外层列表），不整段飞出
* [ ] 非行首退格 → 只是删一个字符，列表结构不变
* ⚠️ 上游：复选框后不写内容的空任务项识别不了复选框，标记显示成文本 `[ ]`（渲染层仍是上游行为）

### 1.3 TOC

* [ ] 滚动正文时，TOC 高亮当前章节并自动滚动到可视区（判定与吸顶条同源）
* [ ] 高亮**只随阅读前进、不在两节交界处来回跳**（同一位置连采 6 次结果一致）
* [ ] 非固定态下 TOC 更早自动出现（左侧空白 ≥ 面板宽度 55% 即展开），且**面板保持完整宽度**
* [ ] 左侧空白放不下面板时，正文自动让位（面板**不覆盖正文**）；拖宽面板时同样只推正文

### 1.4 切标签过渡

* [x] 编辑器不重建：撤销/重做历史、滚动位置、折叠状态在切换标签期间全程保留
* ⚠️ 平台：切回标签时编辑区会空白一下（VS Code 对保活 webview 的行为——隐藏期间撤掉内容尺寸、激活时重设）；已量化为宿主结构性开销，扩展侧无法干预
