# Spec：Mermaid 预览缩放

> 创建日期：2026-09-04
> 状态：已实现（v1.2.0，2026-09-13）
> 归属：v1.2 批次二（借鉴功能预评估：官方无 preview 缩放能力，低风险，DOM 层缩放不影响文档）

## 需求范围

Mermaid 预览面板支持缩放（放大/缩小/重置），缩放后横向溢出可滚动查看，方便阅读大型图表。

## 交互边界

- **缩放机制**：DOM 层缩放（SVG `width` 百分比调整），不触碰文档内容；范围 0.4×–3×，步进 0.2
- **控制条**：预览右上角悬浮「＋ / − / ×」三个按钮（i18n：Zoom In / Zoom Out / Reset Zoom，词条已存在）
- **滚动**：缩放 >100% 时预览容器横向滚动查看（原生 overflow）
- **重绘保持**：主题切换重绘 SVG 后控制条重新挂载、缩放倍率保持
- **只影响 mermaid 预览**：其他代码块预览（renderPreview 返回 null 的语言）不受影响

## 验收标准

- [ ] 预览出现控制条，＋/− 缩放范围钳制在 0.4–3，× 重置为 1
- [ ] 放大后容器可横向滚动，缩小后无空白异常
- [ ] 主题切换后控制条仍在、倍率保持
- [ ] 缩放纯函数单元测试（钳制边界、步进）
- [ ] 全屏 lightbox（既有功能）与缩放共存正常
