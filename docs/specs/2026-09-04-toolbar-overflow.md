# Spec：工具栏溢出菜单

> 创建日期：2026-09-04
> 状态：实施中
> 归属：v1.2 批次二（roadmap 已有条目：替代 container query + flex-wrap 方案）

## 需求范围

窗口收窄时，顶栏（官方 Crepe top-bar，Vue 渲染）放不下的按钮自动收进右侧「⋯」溢出菜单；点开弹出面板显示被收起的按钮（图标 + 名称），点击执行原按钮动作。替代当前 `<720px` 换行方案（布局跳动、高度变化不可控）。

## 交互边界

- **实现约束**：官方 topBar 是 Vue 组件，禁止 DOM 移动（破坏虚拟 DOM）；方案 = 隐藏 class 控制显示 + 外部（body 级）溢出面板渲染按钮副本
- **收起策略**：从右往左逐按钮收起（保持组顺序与分隔线语义）；heading 下拉与 history 组最后收起；始终为「⋯」按钮预留固定宽度
- **显示控制**：对被收起按钮加隐藏 class（`display: none`）；Vue patch 可能覆盖 class，监听 topBar 子树 Mutation + 选区变化时重应用（自愈）
- **测量与重算**：ResizeObserver（topBar）+ window resize + 文档变化，rAF 节流重算预算
- **溢出面板**：fixed 定位在 topBar 右下方，含被收起按钮列表（icon + i18n 名称 + active 态）；点击执行 onRun 后关闭；Esc/外点/滚动关闭；幂等防重
- **按钮元数据**：`buildTopBar` 回调中从 `builder.build()` 快照 groups（key/icon/onRun），key→i18n 名称查表（替代现有按序 TOOLTIPS 映射的脆弱写法，仅本组件使用）
- **主题**：全部 `--vscode-*` 变量

## 验收标准

- [ ] 窗口收窄：按钮从右往左逐个收进「⋯」；放大逐步还原；无布局跳动
- [ ] 溢出面板显示被收起按钮（图标+名称），点击执行对应动作并关闭
- [ ] 收起/还原过程中按钮 active 态与 tooltip 不失效（重应用自愈）
- [ ] 现有 container query 换行规则移除，无残留死样式
- [ ] 预算计算纯函数补单元测试（边界：刚好放下/超一个/全收起）
- [ ] 各功能按钮（表格网格选择器、图片、列表切换等）在溢出菜单中行为与直接点击一致
