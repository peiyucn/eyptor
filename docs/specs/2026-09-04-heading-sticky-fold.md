# Spec：标题吸顶 + 折叠

> 创建日期：2026-09-04
> 状态：实施中
> 归属：v1.2 批次二（roadmap 已有条目；实现方案参考 git-xing/md-wysiwyg-editor v0.2.0–0.3.2，其 sticky 布局历经 0.2.2/0.2.1/0.3.2 三次修复，epytor 直接采用其最终方案）

## 需求范围

1. **标题吸顶**：长文档滚动时，视口顶部的当前章节标题显示在顶栏下方的吸顶条中；滚动到下一个标题时吸顶条更新并产生「推挤」过渡；点击吸顶条跳回该标题
2. **同级折叠**：hover 标题时在标题左侧显示折叠箭头，点击折叠/展开该标题到下一个同级（或更高级）标题之间的全部内容

## 交互边界

- **吸顶条**：
  - 位置：`.milkdown-top-bar` 下方，left/width 对齐当前标题，`translateY` 实现被下一标题推挤
  - 内容：折叠开关（chevron）+ 标题层级标记 + 标题文本（字体与标题一致）
  - 显示条件：存在 active 标题（rect.top ≤ topbarBottom 的最后一个可见标题）
  - 更新时机：scroll / resize / 文档变化（rAF 节流）；编辑器生命周期结束必须清理（listener、observer、DOM）
  - 点击吸顶条（非折叠按钮）→ 滚动至该标题
- **折叠**：
  - 实现：ProseMirror Plugin + Decoration（折叠状态存 PluginKey state，**不修改文档**；折叠仅 DOM 隐藏，源码/保存不受影响）
  - 折叠范围：标题之后到下一个「层级 ≤ 当前」的标题之前；无后续同级标题则到文档尾
  - 折叠块应用 `display: none`（Decoration class），光标在折叠区域内时先移出再折叠（TextSelection.near）
  - 折叠状态在 docChanged 时按 mapping 跟随迁移；标题被删除则状态自动清理
  - 折叠标题末尾按 Enter 自动展开
- **无障碍**：折叠按钮 `aria-expanded`/`aria-label`；吸顶条角色为导航辅助
- **主题**：全部 `--vscode-*` 变量

## 验收标准

- [ ] 长文档滚动：吸顶条显示当前章节，跨标题切换正确，推挤过渡平滑
- [ ] 点击吸顶条跳回标题
- [ ] hover 标题出现折叠箭头；折叠后后续内容隐藏，标题间折叠互不影响
- [ ] 折叠状态下切换文本编辑器→源码不受影响（文档未被修改）
- [ ] 折叠标题尾部按 Enter 展开
- [ ] 编辑（增删标题/内容）后折叠状态不失效、不误折叠
- [ ] 折叠范围纯函数补单元测试（同级边界/更高级边界/文档尾/无内容）
- [ ] TOC 面板、行定位、网格选择器等功能无回归
