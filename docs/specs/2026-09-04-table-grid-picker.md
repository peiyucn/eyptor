# Spec：表格网格选择器（Table Grid Picker）

> 创建日期：2026-09-04
> 状态：已实现（v1.2.0，2026-09-13）
> 归属：v1.2 批次二（借鉴 git-xing/md-wysiwyg-editor v0.3.0 表格网格选择交互）

## 需求范围

顶栏「插入表格」按钮点击后弹出 N×M 网格选择器，hover 预览行列范围，点击后在光标处插入指定行列数的表格，替代当前固定 3×3 的直接插入。

## 交互边界

- **打开**：点击顶栏 table 按钮 → 按钮下方弹出网格面板（8×8 单元格），初始无高亮
- **预览**：hover 单元格 (r, c) → 高亮左上角 r×c 区域（含表头行），面板标题实时显示 `r×c`
- **插入**：点击单元格 → 调用官方 `insertTableCommand`（`{ row: r, col: c }`，自带默认 3×3 兜底）插入表格并关闭面板
- **关闭**：Esc、点击面板外部、编辑器滚动 → 关闭
- **幂等**：面板打开期间再次点击 table 按钮 → 先关闭再打开（防重复面板）
- **无障碍**：面板容器 `role="grid"`、单元格 `role="gridcell"` + `aria-label`（如「3 行 4 列」）
- **样式**：全部使用 `--vscode-*` CSS 变量，适配亮/暗主题；面板定位跟随按钮（fixed，避开视口边缘）

## 验收标准

- [ ] 点击 table 按钮弹出网格，hover 高亮与标题计数正确
- [ ] 点击 3×4 单元格 → 插入 3 行 4 列表格（含表头），光标进入首个单元格
- [ ] 行列数小于 3 时（如 1×2）正常插入（官方命令兜底行为以实测为准）
- [ ] Esc / 外部点击 / 滚动均能关闭；重复点击按钮无重复面板
- [ ] 亮暗主题下样式正常
- [ ] 纯逻辑（hover 索引 → 行列数）提取为独立模块并补单元测试
- [ ] 官方 3×3 直接插入路径移除后无死代码残留
